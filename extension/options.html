Endpoints

Leave defaults unless hosting moves. Primary host is GitHub Pages (published by the repo's data workflow); the GCS bucket is the manual fallback. If a host is unreachable the extension falls back to bundled data silently.

Pages to skip

Jobber list views show dozens of addresses at once, so suggestions are hidden there. One path per line, query strings ignored. Only an exact path is skipped, so detail pages such as /clients/151344135, /jobs/150363992 and /clients/new still get badges.

Jobber tax-group labels

Each Ohio jurisdiction (county + optional transit district) maps to the Jobber tax-group name the badge suggests. Built-in defaults match Steambrite's current Jobber groups. Type an override to change one; clear the box to go back to the default. Rows marked "unmapped" show the data file's suggested name — add that group in Jobber (or map it here) if you serve that area.
